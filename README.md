# 🍕 Pizza Sales Analysis | Power BI Dashboard

## 📌 Project Overview

In this project, I analysed pizza sales data using PostgreSQL and Power BI. The goal was to understand sales performance, find out which pizzas were selling the most, and identify patterns in customer orders. I created an interactive dashboard to explore revenue, order trends, pizza categories, and size preferences.

## 🎯 Project Objectives

- Calculate total revenue, average order value, total pizzas sold, and total orders.
- Analyze daily and monthly order trends.
- Find out which pizza categories and sizes contribute most to sales.
- Identify the top 5 and bottom 5 pizzas by revenue, quantity sold, and total orders.
- Compare the performance of different pizzas.
- Use filters to explore sales data across different dates and categories.

## 🛠️ Tools & Technologies

- **PostgreSQL** – Writing SQL queries to analyze pizza sales data.
- **Microsoft Power BI** – Creating the dashboard and visualizations.
- **Power Query** – Cleaning and preparing the data.
- **DAX** – Creating measures for KPIs and sales calculations.
- **Data Modeling** – Organizing data for analysis and reporting.
